# AI Gesture Controller

Добро пожаловать в AI Gesture Controller — программу для управления компьютером с помощью жестов рук! 
Эта программа позволяет вам переключать музыку, регулировать громкость и управлять курсором мыши, просто двигая руками перед веб-камерой.

## 🚀 Как запустить программу
Вам не нужно устанавливать сложные среды разработки или знать языки программирования. 
1. Скачайте файл `frontend.exe` (или архив с программой, если предоставлен).
2. Дважды кликните по файлу `frontend.exe`, чтобы запустить его.
3. Программа автоматически найдет вашу веб-камеру. (При первом запуске Windows может запросить разрешение на использование камеры — нажмите "Разрешить").

*Для разработчиков: запуск из исходного кода осуществляется командой `python frontend.py` (требуются библиотеки opencv-python, mediapipe, customtkinter, pygame, pyautogui, pystray).*

## ⚙️ Первичная настройка
1. Откройте программу и перейдите на вкладку **«Настройки»**.
2. Убедитесь, что в окошке справа вы видите себя (камера работает).
3. Нажмите кнопку **«Выбрать музыку»** и выделите аудиофайлы (форматы .mp3 или .wav), которые хотите послушать.
4. Вернитесь на вкладку **«Главная»**.

## 🖐 Инструкция по жестам

### Режим «Управление плеером»
Включите этот режим на главной странице. Убедитесь, что руки хорошо освещены.
- 🤙 **Старт воспроизведения:** Покажите жест «52». Поднимите обе руки: на левой руке покажите все 5 пальцев (открытая ладонь), на правой — только указательный и средний (жест Peace/Виктория).
- 👊 **Пауза:** Сожмите левую руку в кулак.
- 🖐 **Продолжить:** Полностью раскройте правую ладонь (покажите все 5 пальцев).
- 👍 **Следующий трек:** Поднимите большой палец на правой руке (жест «Класс»).
- 👍 **Предыдущий трек:** Поднимите большой палец на левой руке.
- ☝️ **Громкость:** Соберите левую руку в кулак, выпрямите только указательный палец. Двигайте им вверх (громче) или вниз (тише).

### Режим «Управление мышью»
Переключитесь в этот режим с помощью кнопки на главном экране.
- 👆 **Движение мыши:** Выпрямите только указательный палец на правой руке и двигайте кистью в воздухе.
- ✌️ **Левый клик (ЛКМ):** К указательному пальцу на правой руке добавьте выпрямленный средний палец.
- 🤙 **Правый клик (ПКМ):** К указательному пальцу на правой руке добавьте выпрямленный мизинец.
- ↕️ **Прокрутка (Скролл):** Выпрямите указательный палец на левой руке и совершайте движения кистью вверх или вниз для прокрутки веб-страниц.

## 🛑 Как закрыть программу
Если вы нажмете "крестик" в правом верхнем углу, программа просто свернется в системный лоток (рядом с часами) и продолжит работать в фоне.
Чтобы полностью закрыть программу, нажмите большую красную кнопку **«Выход»** на главной вкладке, либо кликните правой кнопкой мыши по иконке программы рядом с часами и выберите «Выход».
