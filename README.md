# AI Gesture Controller 🤖

Кроссплатформенное десктопное приложение для бесконтактного управления операционной системой Windows и медиаплеером с помощью жестов рук через обычную веб-камеру. 

## Описание файлов проекта
* `frontend.py` — главный модуль приложения. Содержит логику компьютерного зрения (MediaPipe), эмуляцию мыши (PyAutoGUI), аудиоплеер (Pygame) и графический интерфейс (CustomTkinter).
* `requirements.txt` — список необходимых библиотек и зависимостей для работы программы.
* `ТЗ Курсовая работа` — документация с функциональными требованиями к проекту.

## Требования
* ОС: Windows 10/11 (x64)
* Python: версия 3.9 и выше
* Наличие любой подключенной веб-камеры

## Инструкция по запуску (через терминал)

**Шаг 1. Клонируйте репозиторий**
git clone https://github.com/ExSp4ne/MAINproject.git
cd MAINproject

**Шаг 2. Установите все зависимости**
pip install -r requirements.txt

**Шаг 3. Запустите приложение**
python frontend.py
